# Internal Linking SEO Strategy — H & J Cabinets

**Date:** 2026-04-26  
**Scope:** Full site — 110 pages  
**Approach:** Thematic Cluster Inline Linking

---

## Context

The site has rich, relevant content across three major sections (33 insights articles, 36 custom-cabinets pages, 24 featured-home projects) but minimal cross-section linking. About 20 insights articles have zero internal links. Custom-cabinets pages mostly only link to `/contact/`. The featured-homes and custom-cabinets sections barely reference the insights content.

Goal: Add inline contextual links throughout all pages to create a topically interconnected site, strengthen topic authority for Google, and route users naturally toward conversion (contact/custom-cabinets).

---

## Design Decisions

- **Inline only** — Links added to existing body text using appropriate anchor phrases. No new sections, no "Related Articles" blocks.
- **All sections** — Insights articles, custom-cabinets pages (hub + product types + design styles + locations), featured-home project pages, and core pages (gallery, testimonials, difference).
- **2–6 new links per page** depending on available body text; thin pages (style stubs) get fewer.
- **No link duplication** — if a link already exists, skip it.

## Implementation Strategy

The site uses static HTML files. All changes are direct edits to `index.html` files in each page directory. No build step required.

**Execution order (parallel subagents by section):**
1. **Agent A** — Insights: Kitchen cluster (8 articles)
2. **Agent B** — Insights: Bathroom + Storage clusters (5 articles)
3. **Agent C** — Insights: Materials cluster (7 articles)
4. **Agent D** — Insights: Buyer Journey cluster (7 articles)
5. **Agent E** — Insights: Location cluster (7 articles)
6. **Agent F** — Custom-cabinets: Kitchen + Bathroom + Storage service pages (product types)
7. **Agent G** — Custom-cabinets: Style pages (9 pages)
8. **Agent H** — Custom-cabinets: Location pages (8 pages)
9. **Agent I** — Featured homes: Newport area projects (8 projects)
10. **Agent J** — Featured homes: Irvine/Laguna/Other projects (15 projects)
11. **Agent K** — Core pages: difference/, gallery/, testimonials/, about/

**Per-agent process:**
1. Read the page HTML
2. Find the anchor text phrase in the existing body content
3. Wrap with `<a href="/target-path/">anchor text</a>` — using absolute paths
4. Ensure no duplicate links (skip if target already linked on that page)
5. Edit the file

**Link format:** All internal links use absolute root-relative paths (e.g., `/custom-cabinets/kitchen/`) for consistency.

**Fallback for thin pages:** Style pages (rustic, cottage, etc.) may have minimal body text. If the suggested anchor phrase is not present, use the nearest equivalent phrase in the existing text. If no suitable phrase exists, skip that link rather than forcing awkward placement.
